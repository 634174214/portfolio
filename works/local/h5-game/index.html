全民射嫦娥-点击射击小游戏

该游戏为“射击类”小游戏，通过点击屏幕上的月饼计数，根据不同的游戏个数，导向不同的外链。比较适合节假日宣传、现场活动、客户产品宣传等场景。

注：其中元素均可更换。比如月饼元素替换为粽子、饺子、家电、客户LOGO等，嫦娥元素替换为客户公司吉祥物等。均可根据实际应用场景进行设计。 code
跑酷奔向苏宁-小游戏

该游戏为“跑酷类”小游戏，通过点击屏幕上左右方向键左右移动，躲避障碍和加速操作。适合活动宣传、客户产品宣传，政务活动宣传等。

注：其中元素均可更换。比如跑酷小人元素替换为客户公司吉祥物、加速减速图标替换为客户logo，最终目的高楼替换为某商场等。均可根据实际应用场景进行设计。 code
高新区项目投资-小游戏

该游戏为“模拟投资类”小游戏，通过点击不同项目实现数据累加，最终出现导向链接。适合活动宣传、金融类新闻引导关注。

注：其中元素均可更换。比如每个投资项目图标替换为指定的项目图标，背景图替换为青岛建筑物元素等。均可根据实际应用场景进行设计。 code
接金币-小游戏

该游戏为“接金币”小游戏，通过点击屏幕下方位置，控制人物横向移动，收货上方掉下的金币。本游戏适应性较广，可以应用于各种场景，比如节日场景，天上掉粽子、月饼等。
